# poop_02_t01
Tarea para la unidad 2 del modulo programación orientada a objetos en lenguaje python
## Enunciado
**Desarrolla una aplicación modular en Python que simule un sistema de domótica donde diferentes dispositivos 
(sensores, bombillas, cerraduras, etc.) se gestionan desde un Hub central.
El objetivo es aplicar Programación Orientada a Objetos (POO) para organizar el código de forma estructurada, reutilizable y extensible, 
poniendo en práctica:**
  +	Clases, objetos y herencia.
  +	Encapsulación.
  +	Polimorfismo mediante clases abstractas y Protocols.
  +	Métodos estáticos y de clase.
  +	Estructuras de control y datos: bucles, condicionales, listas, diccionarios.
  +	Manejo de excepciones propias.
